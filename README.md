# 3D-CANAL
data and software for modeling 3D-CANAL polymer

The file Data.xlsx includes all the data used to plot Figures 3-10 in the Manuscript. These data are generated using the GROMACS and evap codes. The GROMACS can be accessed by the website [https://www.gromacs.org/]. The evap (evap.sh) is coded for simulating the evaporation, and its usage is described in the comments in it. All other files except Data.xlsx and evap.sh are required to perform the evaporation of a sample solution.
